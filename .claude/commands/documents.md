# Documents

Read CLAUDE.md first. Then run:

```bash
npm run docs                       # every document
npm run docs -- owner-statement    # one kind: owner-statement, clean-run-sheet, letting-record
```

Files land in docs-out/. They use brand.json for the business name and colours. Say which files were written. Print to PDF from the browser. Nothing is sent.
